Istoria Pipeline

A private publishing tool by Panta Studio.

Istoria Pipeline is an internal tool used by a single person to publish educational history documentaries to the YouTube channel Istoria of Everything. It is not a public service, and no one else can sign in to it.

How it uses YouTube

This tool uses YouTube API Services to upload videos that the channel owner has reviewed and approved, set their titles, descriptions and thumbnails, and read the channel's own video statistics. It only ever accesses the owner's own channel.

Use of this tool is subject to the YouTube Terms of Service and the Google Privacy Policy.
