Privacy Policy

Istoria Pipeline, operated by Panta Studio. Last updated October 14, 2026.

Istoria Pipeline is a private, internal tool. It is used only by its owner to publish and manage videos on the owner's own YouTube channels, Istoria of Everything and Paddle the Duck. It is not offered to the public, and no other users can sign in to it.

YouTube API Services

This tool uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the tool accesses

  • OAuth authorisation tokens for the owner's own Google account, so the tool can upload videos on the owner's behalf.
  • Basic information about the owner's own YouTube channels, such as their names and IDs.
  • Metadata and performance statistics for videos on the owner's own channels, such as titles, descriptions, view counts and watch time.

The tool does not access data about viewers, subscribers or any other YouTube users.

Children's privacy

Paddle the Duck publishes videos made for kids, and every one of its videos is marked as made for kids on YouTube. This tool never collects, stores or processes any personal information from children or any other viewers. It only handles the channel owner's own account and the channel's own aggregate statistics.

How the data is used

The data is used only to upload videos, set their titles, descriptions and thumbnails, and review how the channels' own videos are performing so future content can be planned.

Storage and sharing

Data is stored on a private server controlled by the owner. It is not sold, shared with third parties, or used for advertising. Tokens and statistics are deleted when no longer needed, and in any case within 30 days of access being revoked.

Revoking access

Access can be revoked at any time from the Google security settings page. Once revoked, the tool can no longer access the account.
